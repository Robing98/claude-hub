Before you start

  • The Claude desktop app is installed on the computer.
  • The collector runs on the same computer: hub check prints "Connected". The connector uses the collector configuration, so it needs no address or token of its own.
  • The project has Sessions get their rules from the hub turned on. For a project where it is off, the connector answers that the project keeps its own rule files.

Set up

  1. In the hub repository, run: 
    hub mcp-install
    The command adds the entry {{ server_name }} to the configuration of the desktop app and keeps a backup beside the file.
  2. Quit the Claude desktop app completely, then start it again. Closing the window is not enough: on Windows, select Quit in the menu of the tray icon.
  3. Start a new Cowork chat that is linked to this computer. Ask it: 
    Call hub_rules for the folder D:\dev\claude-hub and tell me which rule sets you got.
    Use a folder of a project that has hub rules turned on.
  4. Reload this page. The machine shows "works" under Connector last used.

Repeat the steps on every computer where you use Cowork. A chat that started before the restart does not get the tools.

Set up by hand

Use this when hub mcp-install cannot find the configuration file. In the desktop app, open Settings > Developer > Edit Config, and add the entry to mcpServers. Replace PYTHON_PATH with the full path of the Python that has the collector, for example D:\\dev\\claude-hub\\.venv\\Scripts\\python.exe. In JSON, write each backslash twice.

{{ entry }}
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json

If it does not work

  • The chat has no hub tools: Quit the desktop app completely and start it again, then start a new chat. Check that the chat is linked to the computer.
  • The connector does not start: Read %APPDATA%\Claude\logs\mcp-server-{{ server_name }}.log. It holds what the connector printed. mcp.log in the same folder holds the connection attempts of the app.
  • "The hub is not reachable": Run hub check on that computer. The connector reaches the hub only where the computer does, so away from home it needs the VPN.
  • You moved the repository or its virtual environment: Run hub mcp-install again. The entry holds the path of Python.
  • hub_rules returns no rules: Turn on Sessions get their rules from the hub on the project page.

Remove

hub mcp-remove

Then quit the desktop app and start it again.
