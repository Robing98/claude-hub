Once per computer: allow waking

The hub only sends the signal. The computer must be set to listen for it. The names of the settings differ between mainboards and network cards.

  1. Connect the computer with a network cable. Over Wi-Fi, waking mostly does not work.
  2. In the firmware setup (BIOS or UEFI), turn on Wake on LAN. Some boards call it Power On By PCI-E, and it only works when ErP is turned off.
  3. In Windows, open Device Manager > Network adapters > the cable adapter > Properties. Under Power Management, tick Allow this device to wake the computer and Only allow a magic packet to wake the computer. Under Advanced, turn on Wake on Magic Packet.
  4. To wake from a full shutdown, turn off Fast startup: Control Panel > Power Options > Choose what the power buttons do.
  5. Put the computer to sleep and select Wake here. Then repeat the test with the computer shut down.

After waking, the computer stops at its sign-in screen. The collector reports again once you are signed in, unless it runs as a task that starts with the computer.

Limits

  • The signal reaches only computers in the same network as the hub server. A laptop that is elsewhere cannot be woken.
  • The signal carries no secret. Any device in the home network can send it.
  • If the signal has to go to another address than 255.255.255.255, set HUB_WAKE_BROADCAST on the server, for example to 192.168.178.255.
