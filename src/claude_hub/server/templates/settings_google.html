Once: create the Google project

Google gives access only to an app that is registered with it. You register your own, so that no third party is involved. The labels in the Google Cloud console can differ from the ones here.

  1. Open console.cloud.google.com with your private Google account and create a project, for example claude-hub.
  2. Under APIs & Services > Library, enable Google Calendar API and Gmail API.
  3. Under Google Auth Platform (earlier: OAuth consent screen), set up the app: any name, your address as support and developer contact, audience External.
  4. Under Audience, select Publish app, so that the status is In production. In the status Testing, Google ends every sign-in after 7 days.
  5. Under Clients, create a client with the application type Desktop app, and download its JSON file.

Google does not review the app, so the sign-in shows the warning "Google hasn't verified this app". That is expected for an app that only you use. If the work account refuses the sign-in, the administrator of the work domain must allow the app: Admin console > Security > API controls.

Per account: sign in

  1. In the hub repository, on a computer with a browser, run: 
    hub google-add private --client PATH_TO_CLIENT_JSON
    private is the label of the account, and PATH_TO_CLIENT_JSON is the file from the last step of the project setup. The command keeps a copy of the file beside the collector configuration, so later calls need no --client.
  2. The browser opens. Select the Google account, select Advanced > Go to claude-hub (unsafe) on the warning, and tick every permission.
  3. The command prints the address of the account. Reload this page: the account shows "works".
  4. Repeat for the second account: 
    hub google-add work

Sessions reach the accounts through the connector. If it is not set up yet, follow Cowork connector (MCP). After an update of the hub, quit the Claude desktop app and start it again, so that it loads the new tools.
