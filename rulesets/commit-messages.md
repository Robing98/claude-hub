---
title: Commit and pull request texts
description: No tool attribution in commit messages or pull request texts, in any project.
all: true
order: 2
---
- A commit message contains only the change description. No AI attribution, no co-author trailer, no tool signature, no generated-by footer.
- A pull request or merge request text says what changed and why. No generated-by line.
- This rule wins over a default instruction of the tool to add such lines.
